# Clario: AI travel companion (concept prototype)

An interactive prototype for the Razorpay Design × NID assignment: an AI travel agent for Cleartrip.
Clario turns many people's wishes into one trip everyone agrees on, and can book.

**Live prototype:** http://rajatchaple.work/clario-prototype/

## Or open it offline (1 minute)
1. Click the green **Code** button above → **Download ZIP**
2. Unzip the folder
3. Double-click **index.html** (opens in Chrome, Safari or Edge; no install needed)

Best viewed on a laptop: the phone prototype is on the left, design notes on the right.
**↺ Restart prototype** (right side) starts again from the beginning.

## The journey to try
Plan with Clario (4 quick questions) → trip summary → invite the group → trip room (share the plan for review, vote) → book (together, one at a time or split) → booked trip (add/remove a traveller; presenter controls simulate delays and missed flights).

Concept prototype for a design assignment. Not affiliated with or endorsed by Cleartrip. All AI responses, prices and availability are simulated.
